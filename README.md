# Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing customer shopping behavior using Python, SQL, and Power BI.

## 📌 Project Overview

This project analyzes customer shopping data to identify purchasing patterns, customer segments, product performance, and factors influencing customer spending and subscriptions.

The project combines data analysis in Python, business-focused SQL queries, and an interactive Power BI dashboard.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Jupyter Notebook
  

🔍 Analysis Performed
Python
Data cleaning and preprocessing
Exploratory data analysis
Customer behavior analysis
Age-group segmentation
Data visualization
SQL


The project answers business questions such as:
Revenue generated by male vs. female customers
Customers using discounts while spending above average
Products with the highest average review ratings
Comparison of Standard vs. Express shipping spending
Spending and revenue comparison between subscribers and non-subscribers
Products with the highest discount purchase rates
Customer segmentation based on previous purchases
Top products within each category
Relationship between repeat purchases and subscription
Revenue contribution by age group
Power BI Dashboard


The interactive dashboard provides insights into:
Total customers
Average purchase amount
Average review rating
Customers by subscription status
Sales by category
Revenue by category
Sales by age group
Revenue by age group
Customer filtering by gender, category, shipping type, and subscription status


📊 Dashboard
The Power BI dashboard provides an interactive view of customer shopping behavior and allows users to filter the analysis based on different customer characteristics.


💡 Key Insights
The analysis helps understand:
Which product categories generate the most sales and revenue
Differences in customer spending behavior
Subscription patterns
Purchasing behavior across age groups
Discount usage among customers
Repeat purchasing behavior
Product performance based on customer reviews


🚀 How to Use
Open the Jupyter Notebook in the python folder to explore the data analysis.
Open customer_analysis.sql to view the SQL business queries.
Open the .pbix file using Power BI Desktop to explore the interactive dashboard.
